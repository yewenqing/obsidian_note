# 五、(c)：理解正则化项到底有什么作用

这一题基本不需要写复杂代码。

你需要把：

12p∥y−β∥22\frac{1}{2p}\|y-\beta\|_2^2

和

λ∥Wβ∥22\lambda\|W\beta\|_2^2

分别展开成求和。

重点解释：

### 第一项

12p∑j=1p(yj−βj)2\frac{1}{2p}\sum_{j=1}^p(y_j-\beta_j)^2

它负责：

> **让模型尽量贴近观测数据。**

---

### 第二项

因为 WβW\beta 本质上是二阶差分，所以它类似：

λ∑j(βj−2βj+1+βj+2)2\lambda \sum_j (\beta_j-2\beta_{j+1}+\beta_{j+2})^2

它负责：

> **惩罚曲线的剧烈弯曲，让拟合结果更加平滑。**

所以这里实际上是在理解：

```text
Data fitting term
       +
Smoothness regularisation
```

两者之间的 trade-off。

然后证明：

∇Lj(β)=−(yj−βj)ej+2λpWTWβ\nabla L_j(\beta) = -(y_j-\beta_j)e_j + 2\lambda pW^TW\beta

这里的意义是：

原来的 loss 可以拆成：

```text

L2
L3
...

```

然后：

```text
Gradient of whole loss
=
average of individual gradients
```

这正是 SGD 可以成立的基础。

# 九、(g)：整份作业数学上最难的一部分

这里开始研究：

# Leave-One-Out Cross Validation

假设我们暂时拿掉：

yjy_j

然后用：

y1,…,yj−1,yj+1,…,ypy_1,\dots,y_{j-1},y_{j+1},\dots,y_p

训练模型。

得到：

β^(−j)\hat\beta^{(-j)}

然后用：

β^j(−j)\hat\beta_j^{(-j)}

预测被拿掉的：

yjy_j

于是：

CV(λ)=1p∑j(yj−β^j(−j))2CV(\lambda) = \frac1p \sum_j (y_j-\hat\beta_j^{(-j)})^2

---

问题是：

如果 p=1000p=1000，你每个 λ\lambda 都要训练 1000 个模型。

非常慢。

---

## 所以 (g) 要你推导一个 shortcut

最终得到：

CV(λ)=1p∑j=1p(yj−β^j1−Sjj)2\boxed{ CV(\lambda) = \frac1p \sum_{j=1}^p \left( \frac{y_j-\hat\beta_j} {1-S_{jj}} \right)^2 }

其中：

S=(I+2λpWTW)−1S=(I+2\lambda pW^TW)^{-1}

这意味着：

原来：

```text
一个 lambda
    ↓
p 次重新训练模型
```

变成：

```text
一个 lambda
    ↓
只训练/求解一次
    ↓
直接算 CV
```

这是整份作业最重要的数学技巧之一。

# 十一、(i)：研究 CV 在统计学上为什么有意义

最后一问从：

```text
Optimization
```

进入：

```text
Statistical Learning
```

假设：

yj=βj∗+ϵjy_j=\beta_j^*+\epsilon_j

其中：

E[ϵj]=0E[\epsilon_j]=0 Var(ϵj)=σ2Var(\epsilon_j)=\sigma^2

你需要证明：

E[CV(λ)]=σ2+1p∑j=1pE[(β^j(−j)−βj∗)2]\boxed{ E[CV(\lambda)] = \sigma^2 + \frac1p \sum_{j=1}^p E[ (\hat\beta_j^{(-j)}-\beta_j^*)^2 ] }

这个式子非常有意义。

右边实际上是：

noise+prediction error\text{noise} + \text{prediction error}

也就是说 CV 并不是一个随便定义出来的数字。

它和：

> **模型对未知真实信号的预测误差**

有直接关系。

然后还要做一个 simulation。

> 直接看真实的 β∗\beta^*，选择让 reconstruction error 最小的 lambda。

|Lambda selection|Mean reconstruction error|
