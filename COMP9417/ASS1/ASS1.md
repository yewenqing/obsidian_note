## 问题 1. 基于梯度的优化

用于寻找函数 $f: \mathbb{R}^{n} \rightarrow \mathbb{R}$ 极小值的一般梯度方法框架定义为：

  

$$x^{(k+1)} = x^{(k)} - \alpha_k \nabla f(x^{(k)}), \quad k = 0, 1, 2, \dots$$

其中 $\alpha_k > 0$ 被称为步长或学习率。考虑以下最小化函数 $g(x) = 2\sqrt{x^3 + 1}$ 的简单例子。首先我们注意到 $g^{\prime}(x) = 3x^2(x^3 + 1)^{-1/2}$。然后我们需要选择一个起始值，比如 $x^{(0)} = 1$。让我们也将步长设为常数 $\alpha_k = \alpha = 0.1$。于是我们有以下迭代过程：

  

- $x^{(1)} = x^{(0)} - 0.1 \times 3(x^{(0)})^2 ((x^{(0)})^3 + 1)^{-1/2} = 0.7878679656440357$
    
      
    
- $x^{(2)} = x^{(1)} - 0.1 \times 3(x^{(1)})^2 ((x^{(1)})^3 + 1)^{-1/2} = 0.6352617090300827$
    
      
    
- $x^{(3)} = 0.5272505146487477$
    
      
    
- $\vdots$
    
      
    

此过程一直持续到我们终止算法（作为一个对您有益的快速练习，编写代码实现它，并将其与函数的真实极小值 $x_* = -1$ 进行比较）。这种方法适用于具有向量值输入的函数，这在机器学习中经常出现。例如，当我们最小化损失函数时，我们是针对权重向量 $\beta$ 进行最小化的。当我们在每次迭代中采用常数步长时，该算法被称为梯度下降（Gradient Descent）。在整道题目中，**请勿使用任何现有的梯度方法实现**，这样做会导致整道题目自动得零分。

### 选择正则化参数

在前面的部分中，我们使用了给定的任意 $\lambda$ 值。另一种选择是使用数据来确定一个好的选择。一个想法是暂时留出一个观测值，对其余观测值进行拟合，并检查拟合的信号对留出的观测值的预测效果如何。对每个观测值重复此操作并对平方预测误差取平均值，就得到了一个可用于比较不同 $\lambda$ 选择的分数。这个过程称为**留一法交叉验证（leave-one-out cross-validation）**。

  

对于剩余部分，假设 $p \ge 3$，对于固定的 $\lambda > 0$，记 $S = (I + 2\lambda p W^T W)^{-1}$。根据第 1(b) 部分，使用所有观测值的拟合信号为 $\hat{\beta} = Sy$。

  

对于 $j = 1, \dots, p$，定义：

  

$$L^{(-j)}(\beta) = \frac{1}{2p} \sum_{i \neq j} (y_i - \beta_i)^2 + \lambda \vert{}\vert{}W\beta\vert{}\vert{}_2^2$$

$$\hat{\beta}^{(-j)} = \arg \min_{\beta} L^{(-j)}(\beta)$$

注意，拟合的信号仍然具有 $p$ 个坐标，我们使用 $\hat{\beta}_j^{(-j)}$ 来预测被留出的观测值 $y_j$。您可以无需证明地假设其中每个最小化问题都有唯一解，并且对于所有 $j = 1, \dots, p$，都有 $0 < S_{jj} < 1$。

  

交叉验证分数为：

  

$$CV(\lambda) = \frac{1}{p} \sum_{j=1}^{p} (y_j - \hat{\beta}_j^{(-j)})^2$$

较小的分数意味着拟合信号对留出观测值的预测更加准确。

正如讲座中所指出的，这里我们简要概述几种梯度下降的变体。回想一下，在梯度下降中，我们的更新规则是：

  

$$\beta^{(k+1)} = \beta^{(k)} - \alpha_k \nabla L(\beta^{(k)}), \quad k = 0, 1, 2, \dots$$

其中 $L(\beta)$ 是我们试图最小化的损失函数。在机器学习中，损失函数通常具有以下形式：

  

$$L(\beta) = \frac{1}{n} \sum_{i=1}^{n} L_i(\beta)$$

即损失是标记为 $L_i$ 的 $n$ 个函数的平均值，并且每个 $L_i$ 仅通过 $(x_i, y_i)$ 依赖于数据。由此可知，梯度也是以下形式的平均值：

  

$$\nabla L(\beta) = \frac{1}{n} \sum_{i=1}^{n} \nabla L_i(\beta)$$

现在我们可以定义一些流行的梯度下降变体：

  

**(i) 梯度下降（GD）（也称为批量梯度下降）：** 这里我们使用完整的梯度，即对所有 $n$ 项取平均值，因此我们的更新规则是：

  

$$\beta^{(k+1)} = \beta^{(k)} - \frac{\alpha_k}{n} \sum_{i=1}^{n} \nabla L_i(\beta^{(k)}), \quad k = 0, 1, 2, \dots$$

**(ii) 随机梯度下降（SGD）：** 在第 $k$ 步中，我们不考虑所有 $n$ 项，而是从 $\{1, \dots, n\}$ 中随机选择一个索引 $i_k$，并更新：

  

$$\beta^{(k+1)} = \beta^{(k)} - \alpha_k \nabla L_{i_k}(\beta^{(k)}), \quad k = 0, 1, 2, \dots$$

在这里，我们使用 $\nabla L_{i_k}(\beta)$ 来近似完整梯度 $\nabla L(\beta)$。

  

**(iii) 小批量梯度下降（Mini-Batch Gradient Descent）：** GD（使用所有项）和 SGD（使用单项）代表了两种可能的极端。在小批量 GD 中，我们在每一步随机选择大小为 $1 < B < n$ 的批次，记其索引为 $\{i_{k_1}, i_{k_2}, \dots, i_{k_B}\}$，然后更新：

  

$$\beta^{(k+1)} = \beta^{(k)} - \frac{\alpha_k}{B} \sum_{j=1}^{B} \nabla L_{i_j}(\beta^{(k)}), \quad k = 0, 1, 2, \dots$$

因此我们仍然在近似完整梯度，但使用的元素多于 SGD 中使用的单个元素。
