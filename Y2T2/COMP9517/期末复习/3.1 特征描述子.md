在计算机视觉中，**特征描述子（Feature Descriptor）** 简单来说就是**特征点的“数字身份证”或“特征名片”**。

  

如果说**关键点检测（Keypoint Detection）** 是回答了“图像中**哪里**有有意义的点”（比如角点、斑点），那么**特征描述子**则是回答了“这个点**长什么样**”。

  

## 核心定义与通俗理解

- **原始数据**：关键点周围的局部像素块（比如 $16 \times 16$ 的 RGB 矩阵）。如果直接比较原始像素，光照一变或图片旋转一下，数值就会发生巨变。
    
      
    
- **特征描述子**：将这个复杂的局部像素块，通过数学提取和统计，转化为一串固定长度的数值向量（例如一个 128 维的向量：$[0.12, 0.05, 0.88, ...]$）。
    
      
    
- **最终目的**：使得**同一个物体在不同视角、光照、大小下拍摄时，提取出的描述子向量尽可能相似**；而**不同物体的描述子向量差距尽可能大**。
    
      
    

## 为什么需要特征描述子？

假设你想在两张照片里找到同一个建筑物的尖顶：

  

1. **不能直接对比像素**：如果照片 $A$ 比较亮，照片 $B$ 比较暗，或者相机旋转了 45 度，对应位置的像素 RGB 值会完全不同。
    
      
    
2. **需要具备“不变性”（Invariance）**：优秀的描述子通常具有以下特性：
    
      
    - **旋转不变性**：图片旋转了，描述子向量基本不变。
        
          
        
    - **缩放/尺度不变性**：相机拉近或推远，描述子向量基本不变。
        
          
        
    - **光照不变性**：环境变亮或变暗，描述子向量基本不变。
        
          
        

有了这个“数字身份证”，计算机只需计算两个向量之间的**欧氏距离**或**汉明距离**，就能瞬间完成两张图的特征匹配。

  

## 常见的特征描述子分类

根据设计方式，描述子主要分为以下三类：

  

### 1. 经典浮点型描述子（精度高、对复杂变化鲁棒）

- **SIFT (Scale-Invariant Feature Transform)**：
    
      
    - **原理**：将关键点周围 $16 \times 16$ 的区域划分为 $4 \times 4$ 个网格，统计每个网格内 8 个方向的梯度直方图，生成 **128 维** 的浮点数向量。
        
          
        
    - **特点**：极其强悍的不变性，是计算机视觉的里程碑算子，但计算量相对较大。
        
          
        
- **HOG (Histogram of Oriented Gradients)**：
    
      
    - **原理**：统计局部区域内的梯度方向分布。
        
          
        
    - **特点**：常用于描述物体的整体轮廓结构（如行人检测、车辆检测）。
        
          
        

### 2. 二进制描述子（计算极快、省内存、适合移动端/SLAM）

- **ORB / BRIEF / FREAK**：
    
      
    - **原理**：不计算复杂的梯度直方图，而是在关键点周围挑选很多对像素点，直接比较它们的灰度大小（如 $I(A) > I(B)$ 则记为 `1`，否则记为 `0`），生成一串由 `0` 和 `1` 组成的二进制串（如 256 位）。
        
          
        
    - **特点**：占用内存极小，匹配时直接使用硬件级别的异或（XOR）运算计算汉明距离，速度比 SIFT 快几个数量级。
        
          
        

### 3. 深度学习描述子（数据驱动、自适应能力强）

- **SuperPoint / HardNet / Patch2Pix**：
    
      
    - **原理**：放弃人工设计规则，直接将图片 Patch 输入到训练好的卷积神经网络（CNN）中，让网络自动提取并输出高维特征向量。
        
          
        

## 总结：特征提取与匹配的全流程

一个完整的传统视觉特征匹配流程通常如下：

  

$$\text{图像输入} \xrightarrow{\text{1. 检测 Keypoints}} \text{找到位置 }(x,y) \xrightarrow{\text{2. 提取 Descriptors}} \text{生成特征向量 } \mathbf{v} \xrightarrow{\text{3. 匹配 Matcher}} \text{计算向量距离并关联}$$

1. **Keypoint Detection（关键点检测）**：找到位置（如 Sobel、Harris、FAST、DoG）。
    
      
    
2. **Feature Description（特征描述）**：生成名片（如 SIFT 描述子、ORB 描述子）。
    
      
    
3. **Feature Matching（特征匹配）**：比对名片（如 Nearest Neighbor 寻找最近邻向量）。


在计算机视觉（尤其是 COMP9517 课程）中，**Haralick**、**SIFT**、**LBP** 和 **Colour Moments** 都是用来提取图像特征的经典**传统特征提取算法（Hand-crafted Feature Extractors）** 。

  

我们可以从**分类维度**快速把它们区分开：

  

-   
    
    **全局纹理/颜色特征（Global Features）**：Haralick, LBP, Colour Moments 。
    
      
    
-   
    
    **局部关键点特征（Local Features）**：SIFT 。
    
      
    

下面为你逐一梳理这四个核心考点的原理、应用场景及对比：

  

## 1. Haralick 特征（Haralick Features）

### 核心定义

Haralick 特征是一种基于**灰度共生矩阵（GLCM, Gray-Level Co-occurrence Matrix）**统计图像**纹理特征**的方法 。

  

### 怎么计算的？

1. **生成 GLCM**：GLCM 记录了在特定的方向（如 $0^\circ, 45^\circ, 90^\circ, 135^\circ$）和距离上，灰度值为 $i$ 的像素与灰度值为 $j$ 的像素**共同出现的频率**。
    
      
    
2. **提取统计量**：从 GLCM 矩阵中计算出 14 种标量统计指标（统称为 Haralick 特征），期末高频考察的指标包括：
    
      
    - **对比度（Contrast）**：衡量局部灰度差异（值越大，纹理越粗糙/对比越明显）。
        
          
        
    - **能量（Energy / Angular Second Moment）**：衡量图像灰度分布的均匀性。
        
          
        
    - **熵（Entropy）**：衡量纹理的随机性/复杂性。
        
          
        
    - **同质性（Homogeneity）**：衡量图像局部灰度的相似程度。
        
          
        

### 应用场景

常用于**材质识别**（如木材、布料）、**医学图像分析**（如区分肿瘤与正常组织的纹理差异）。

  

## 2. SIFT（尺度不变特征变换）

### 核心定义

  

**SIFT (Scale-Invariant Feature Transform)** 是计算机视觉中最经典的**局部关键点检测与描述算子** 。

  

### 核心优势（不变性）

它最大的亮点在于具备极强的**不变性（Invariance）**：

  

-   
    
    **尺度不变性**：通过构建高斯差分金字塔（DoG, Difference of Gaussians）实现 。
    
      
    
-   
    
    **旋转不变性**：为关键点分配主方向（Keypoint Orientation） 。
    
      
    
-   
    
    **光照不变性**：对梯度直方图进行归一化处理 。
    
      
    

### 怎么计算的？

1.   
    
    **尺度空间极值检测**：使用 **DoG 算子** 寻找不同尺度下的候选极值点（斑点/关键点） 。
    
      
    
2. **关键点定位与过滤**：去除低对比度点和边缘响应点。
    
      
    
3.   
    
    **方向分配**：基于局部梯度方向确定主方向，实现旋转不变性 。
    
      
    
4.   
    
    **特征描述子生成**：取关键点周围 $16 \times 16$ 的区域，分为 $4 \times 4$ 的子块，统计每个子块 8 个方向的梯度直方图，最终输出一个 **128 维的特征向量** 。
    
      
    

### 应用场景

  

**图像匹配与拼接（全景图）** 、三维重建、SLAM 视觉定位与建图 。

  

## 3. LBP（局部二值模式）

### 核心定义

  

**LBP (Local Binary Pattern)** 是一种用来描述图像**局部纹理特征**的算子 。它通过比较中心像素与周围像素的灰度相对大小来编码 。

  

### 怎么计算的？

1. 在 $3 \times 3$ 的窗口中，以**中心像素**为阈值。
    
      
    
2. 遍历周围 8 个邻居像素：如果邻居像素值 $\ge$ 中心像素值，则记为 **1**，否则记为 **0** 。
    
      
    
3. 将这 8 个二进制位按顺序串联起来，得到一个 8 位二进制数（转化为十进制即为 $0 \sim 255$ 的 LBP 码） 。
    
      
    
4. 统计整幅图或局部区域的 LBP 码**直方图**作为最终的纹理特征描述子。
    
      
    

### 常用变体

- **圆形 LBP**：支持不同半径 $R$ 和邻居点数 $P$。
    
      
    
- **等价模式（Uniform Patterns）**：减少特征维度，增强鲁棒性。
    
      
    

### 应用场景

  

**人脸识别（Face Recognition）**、微表情识别、纹理分类 。

  

## 4. Colour Moments（颜色矩）

### 核心定义

**Colour Moments** 是一种用于表达图像**颜色分布特征**的全局描述子。它的核心假设是：**图像的颜色分布可以由其低阶概率矩来完整刻画**。

  

### 怎么计算的？

通常在 **HSV** 或 **Lab** 颜色空间（对光照变化比 RGB 更鲁棒）下计算前三阶矩：

  

1. **一阶矩（Mean, 均值 $\mu$）**：反应整张图的平均色彩亮度/主色调。
    
      
    
    $$\mu_i = \frac{1}{N} \sum_{j=1}^{N} P_{ij}$$
    
2. **二阶矩（Standard Deviation, 标准差 $\sigma$）**：反应颜色分布的方差/颜色范围的宽窄。
    
      
    
    $$\sigma_i = \sqrt{\frac{1}{N} \sum_{j=1}^{N} (P_{ij} - \mu_i)^2}$$
    
3. **三阶矩（Skewness, 偏度 $s$）**：反应颜色分布的不对称性/偏斜程度。
    
      
    
    $$s_i = \sqrt[3]{\frac{1}{N} \sum_{j=1}^{N} (P_{ij} - \mu_i)^3}$$
    

对 3 个颜色通道（如 H, S, V）分别计算这 3 个矩，最终得到一个 **$3 \times 3 = 9$ 维** 的极轻量级特征向量。

  

### 应用场景

  

**基于内容的图像检索（CBIR，以图搜图）** 、图像快速粗筛选。
