在计算机视觉与模式识别（Pattern Recognition）流程中，**kNN、SVM、决策树（Decision Trees）与随机森林（Random Forest）**是四种最经典且常用的**统计/机器学习分类器（Classifiers）** 。它们通常接收从图像中提取的特征向量（如 SIFT、HOG、LBP、颜色直方图/矩等） ，通过不同的数学机制学习决策边界，从而完成图像分类、目标识别或像素级分割等任务 。

  

### 1. kNN（K-Nearest Neighbors，K-近邻算法）

-   
    
    **核心思想**：“物以类聚，人以群分” 。kNN 是一种典型的基于实例/惰性学习（Lazy Learning）算法，在训练阶段无需显式拟合复杂的数学模型参数，仅需保存所有训练样本 。
    
      
    
- **工作机制**：
    
      
    1. 给定待测试图像的特征向量 $\mathbf{x}$ 。
        
          
        
    2. 计算 $\mathbf{x}$ 与训练集中所有样本点之间的距离（连续特征常用**欧氏距离** $\Vert{}\mathbf{x}_i - \mathbf{x}_j\Vert{}_2$，离散特征可用汉明距离） 。
        
          
        
    3. 选取距离最近的 $K$ 个训练样本 。
        
          
        
    4. 采用多数投票（Majority Voting）或距离加权投票确定最终类别 。
        
          
        
- **参数与考点特性**：
    
      
    -   
        
        **$K$ 的选择**：$K=1$ 时决策边界复杂，容易过拟合且对噪声极敏感；$K$ 过大时决策边界过于平滑，容易欠拟合；通常选用奇数以避免平票 。
        
          
        
    -   
        
        **优缺点**：简单直观、支持多分类 ；但需要**同质特征与归一化尺度（Homogeneous feature types & scales）** ；在大数据集上预测极其耗时，且在高维特征空间中容易遭受“**维度灾难（Curse of Dimensionality）**”导致距离失效 。
        
          
        

### 2. SVM（Support Vector Machine，支持向量机）

-   
    
    **核心思想**：在特征空间中寻找一个能够将不同类别完全分开、且具有最大化分类间隔（Maximal Margin）的最优超平面（Hyperplane） 。
    
      
    
- **核心数学与机制**：
    
      
    -   
        
        **最大间隔目标**：最大化间隔 $\rho = \frac{2}{\Vert{}\mathbf{w}\Vert{}}$，等价于最小化 $\frac{1}{2}\Vert{}\mathbf{w}\Vert{}^2$ 。
        
          
        
    -   
        
        **支持向量（Support Vectors）**：恰好位于最大间隔边界上的少量关键样本点 。整个最优超平面的几何位置完全由这些支持向量决定，非支持向量样本被移除不会改变决策边界 。
        
          
        
    -   
        
        **软间隔（Soft Margin）**：引入松弛变量 $\xi_i$ 与正则化参数 $C$，允许部分噪声或异常点存在一定程度的错分，以应对特征空间重叠问题 。
        
          
        
    -   
        
        **核技巧（Kernel Trick）**：当样本在原始空间中线性不可分时，通过核函数（如径向基核 RBF/高斯核、多项式核）将低维特征隐式映射到高维空间，在高维空间中实现线性划分 。
        
          
        
-   
    
    **视觉应用**：与 **HOG 结合用于行人/车辆检测** ，或与 **词袋模型（BoW）直方图特征结合进行场景与物体分类** 。
    
      
    

### 3. Decision Trees（决策树）

-   
    
    **核心思想**：通过一系列“如果-那么（if-then）”的树状决策规则将高维特征空间递归划分为轴对齐的超矩形子区域 。
    
      
    
- **工作机制**：
    
      
    1. 从包含全部样本的根节点开始，利用统计指标衡量当前集合的纯度/不确定性，如**信息熵（Entropy）** $H(S) = -\sum p(c_i) \log_2 p(c_i)$ 。
        
          
        
    2. 遍历候选特征，选择使得信息增益（Information Gain, IG）或基尼不纯度（Gini Impurity）最大化的特征及阈值进行节点二分分裂 。
        
          
        
    3. 递归分裂子节点，直到达到纯节点或满足停止条件（如最大深度、叶子节点最小样本数） 。
        
          
        
-   
    
    **优缺点**：模型具有极强的可解释性与可视化能力，天然支持离散/连续混合特征 ；但作为贪心构建的单模型，**极易在训练集上过拟合**，通常需要剪枝（Pruning）处理 。
    
      
    

### 4. Random Forest（随机森林）

-   
    
    **核心思想**：基于集成学习（Ensemble Learning）中的 **Bagging（Bootstrap Aggregating，自举汇聚法）** 思想 ，通过构建并组合大量相互独立的决策树来降低单棵树的高方差，提高泛化能力 。
    
      
    
- **核心随机化机制（两重随机性）**：
    
      
    1.   
        
        **样本子集随机（Bootstrap 采样）**：对原始训练集进行有放回的随机重采样，为每棵树生成独立的训练子集 。
        
          
        
    2.   
        
        **特征子集随机**：在决策树的每个节点进行分裂时，不再遍历全部 $M$ 个特征，而是随机抽取 $m \ll M$ 个候选特征，从中挑选最优特征进行分裂 。
        
          
        
- **决策规则**：
    
      
    -   
        
        **分类任务**：所有决策树并行预测，采用多数投票（Majority Voting）确定最终类别 。
        
          
        
    -   
        
        **回归任务**：所有决策树预测结果取算术平均值 。
        
          
        
- **性能规律与考点特性**：
    
      
    - 随机森林的分类误差率受两个关键因素影响：**单棵树的分类强度（Strength）**和**树之间的相关性（Correlation）** 。
        
          
        
    -   
        
        **增强单棵树的独立性/降低树间相关性**，或者**提高单棵树的分类强度**，都能有效降低随机森林的整体分类错误率 。
        
          
        

### 四者核心特性对比总结

|**分类器**|**学习范式**|**核心数学/决策原理**|**对特征尺度敏感度**|**优点**|**缺点 / 局限**|
|---|---|---|---|---|---|
|**kNN**|惰性学习 / 基于实例|计算特征空间距离 + $K$ 邻居多数投票|**极高**（需归一化）|无需显式训练、直观|预测慢、高维空间距离失效（维度灾难）|
|**SVM**|判别式模型|寻找最大分类间隔超平面 + 核技巧|较高（涉及距离与内积）|泛化能力强、高维稀疏特征（如BoW）表现优异|多分类需扩展（OvR/OvO）、大规模训练较耗时|
|**决策树**|树状空间划分|递归分裂 + 最大信息增益/基尼系数|低（基于单特征阈值划分）|可解释性好、支持混合特征|极易过拟合、泛化性能一般|
|**随机森林**|集成学习（Bagging）|双重随机（样本+特征）+ 多数投票集成|低|准确率高、抗过拟合、可评估特征重要性|模型较大、丧失了单棵决策树的直观可解释性|
