在计算机视觉和数字图像处理中，邻域运算/处理（Neighborhood Operations & Processing）是一种基于图像局部区域（而非单个像素）的图像处理技术 。

  

### 1. 什么是邻域运算？

与点运算（Point Operations）仅依赖输入图像中同一位置的单个像素值不同，**邻域运算**在计算输出图像中某一像素点 $(x, y)$ 的值时，**不仅依赖该点本身的像素值，还依赖其周围一定范围（如 $3 \times 3$、$5 \times 5$ 等窗口或核）内的邻域像素值** 。

  

- **数学表达式（以线性邻域卷积为例）：**
    
      
    
    $$g(x, y) = \sum_{i=-n}^{n} \sum_{j=-m}^{m} f(x-i, y-j) \cdot h(i, j)$$
    
    其中 $f(x, y)$ 为输入图像，$h(i, j)$ 为卷积核/模板（Kernel/Filter），$g(x, y)$ 为输出图像 。
    
      
    

### 2. 邻域运算与点运算的对比

|**特性**|**点运算 (Point Operations)**|**邻域运算 (Neighborhood Operations)**|
|---|---|---|
|**依赖范围**|仅依赖单点像素本身|依赖目标像素及其周边邻域（如 $3 \times 3$ 窗口）|
|**核心机制**|灰度映射关系（如查找表 LUT）|滑动窗口操作、卷积或非线性选择|
|**代表技术**|伽马校正、对比度拉伸、直方图均衡化|均值滤波、高斯滤波、中值滤波、Sobel 边缘检测|
|**主要目的**|调整图像亮度、对比度、动态范围|图像平滑（降噪）、锐化、边缘提取、特征检测|

### 3. 邻域运算的核心概念与常见操作

#### (1) 滑动窗口与卷积核（Kernel/Filter）

-   
    
    **卷积核/滤波器**：通常是一个小尺寸的数值矩阵（如 $3 \times 3$） 。
    
      
    
-   
    
    **处理过程**：将卷积核中心与当前像素对齐，使核内每个权重与对应邻域像素相乘后求和，计算结果赋给当前像素 。
    
      
    

#### (2) 边界处理（Border / Edge Handling）

当滑动窗口到达图像边缘时，核的一部分会超出图像边界，常见的边界扩展方法包括 ：

  

-   
    
    **零填充（Padding）**：在图像边界外填充 0 或常数 。
    
      
    
-   
    
    **钳制/边缘复制（Clamping/Replication）**：将图像边缘的像素值向外扩展 。
    
      
    
-   
    
    **镜像（Mirroring）**：以边界为轴，将内部像素镜像翻转到边界外 。
    
      
    
-   
    
    **环绕（Wrapping）**：将图像看作周期性拓展（左连右、上连下） 。
    
      
    

#### (3) 常见的邻域运算类型

1. **平滑/降噪（Smoothing / Noise Reduction）**
    
      
    -   
        
        **均值滤波（Mean Filter）**：取邻域像素的平均值，用于减少加性噪声 。
        
          
        
    -   
        
        **高斯滤波（Gaussian Filter）**：权重按高斯分布衰减（中心大、边缘小），能在平滑的同时更好地保留细节 。
        
          
        
    -   
        
        **中值滤波（Median Filter）**：取邻域像素的中位数（非线性滤波），对去除**椒盐噪声**特别有效，且能保护边缘 。
        
          
        
2. **边缘检测与锐化（Edge Detection & Sharpening）**
    
      
    -   
        
        **一阶导数算子（Sobel / Prewitt / Roberts）**：检测局部强度变化率（梯度），突出图像中的边缘 。
        
          
        
    -   
        
        **二阶导数算子（Laplacian 算子）**：利用二阶导数的零交叉点定位边缘 。
        
          
        
    -   
        
        **非锐化掩模（Unsharp Masking）**：用原图减去平滑图得到高频细节掩模，再加回原图实现锐化 。


  
## 邻域运算就是卷积吗
**不完全是。** **卷积（Convolution）只是邻域运算（Neighborhood Operations）的一种典型代表（主要是线性邻域运算），邻域运算的范畴比卷积要大得多。**

  

### 1. 包含关系：邻域运算 vs 卷积

-   
    
    **邻域运算（大概念）**：只要在计算某个像素的输出值时，**使用了该像素周围局部区域（邻域）内的像素信息**，这种处理都称为邻域运算 。
    
      
    
- **卷积（子集）**：属于**线性邻域运算**。它的核心是通过一个小矩阵（卷积核/滤波器）与邻域像素逐点相乘并求和（加权求和）。
    
      
    

### 2. 邻域运算的两大类别

邻域运算根据计算方式是否为“加权求和”可以分为两大类：

  

#### (1) 线性邻域运算（即各种形式的“卷积”）

这类运算本质上都是卷积核与邻域像素的**乘加操作**：

  

- **均值滤波（Mean Filter）**：算术平均（权重全为 $1/N$ 的卷积）。
    
      
    
- **高斯滤波（Gaussian Filter）**：按高斯分布衰减的加权平均。
    
      
    
- **Sobel / Laplacian 算子**：用于提取边缘的一阶/二阶导数卷积。
    
      
    

#### (2) 非线性邻域运算（**不是**卷积）

这类运算同样使用了邻域像素，但计算过程包含**排序、极值选择、逻辑判定或非线性函数**，无法用普通的卷积核加权求和来表达：

  

- **中值滤波（Median Filter）**：将邻域内所有像素值进行**排序**，取中间值。它没有卷积核的乘加权重，对去除椒盐噪声极有效。
    
      
    
-   
    
    **最大值 / 最小值滤波（Max/Min Filtering）或最大池化（Max Pooling）**：取邻域内的最大值或最小值 。
    
      
    
- **形态学处理（Morphology）**：如**膨胀（Dilation）**和**腐蚀（Erosion）**，利用结构元素对邻域像素进行集合并/交运算。
    
      
    
- **双边滤波（Bilateral Filter）**：同时考虑空间近远和像素灰度相似度的非线性滤波（权重随着图像局部内容动态改变）。
    
      
    

### 总结

- **卷积** = 邻域像素 + **加权乘加求和**
    
      
    
-   
    
    **非卷积邻域运算** = 邻域像素 + **排序 / 极值选择 / 逻辑比较**
    
      
    

因此，**所有的卷积都是邻域运算，但邻域运算不单单只有卷积** 。
