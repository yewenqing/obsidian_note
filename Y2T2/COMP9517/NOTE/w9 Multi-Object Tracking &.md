
  

### 第一份讲义：Multi-Object Tracking（多目标跟踪, MOT）

该部分讲义系统性地讲解了多目标跟踪的**问题定义、数学建模、核心挑战、经典与现代跟踪算法（SORT / DeepSORT / ByteTrack / FastTracker）**以及**评估指标体系**。

  

#### 1. MOT 核心定义与应用场景

- **任务目标**：在输入视频中**定位多个目标**、**保持每个目标的唯一身份（ID）**并生成各自的**运动轨迹**。
    
      
    
- **层级定位**：MOT 作为计算机视觉中的中层任务（Mid-level CV task），是动作识别（Action Recognition）、姿态估计（Pose Estimation）与行为分析等高层任务的基础。
    
      
    
- **应用领域**：智能监控（Surveillance）、运动分析（Sports Analytics）、手术工具跟踪（Surgical Tools）、交通监控（Traffic Monitoring）、异常行为检测以及生物群体跟踪等。
    
      
    

#### 2. 跟踪的核心挑战

- **通用视觉挑战**：几何视角/尺度变化、光照变化、物体被遮挡（Occlusion）、非线性运动、图像模糊及场景中存在相似目标。
    
      
    
- **MOT 特有挑战**（相比单目标跟踪 SOT）：
    
      
    1. 需要动态确定/管理场景中的目标数量（轨迹的初始化与终止）；
        
          
        
    2. 频繁的相互遮挡与交错、多目标间的相互作用与 ID 保持、跨相机多视点跟踪。
        
          
        

#### 3. 数学建模（MAP 贝叶斯估计）

MOT 被形式化为一个多元状态估计问题：

  

- 设第 $t$ 帧中第 $i$ 个目标的状态为 $s_t^i$，所有 $M_t$ 个目标状态为 $S_t = (s_t^1, \dots, s_t^{M_t})$，历史全序列状态为 $S_{1:t}$；观测序列为 $O_{1:t}$。
    
      
    
- **目标**：在给定所有观测序列的条件下，求联合状态的最大后验概率（MAP）：
    
      
    
    $$\hat{S}_{1:t} = \arg\max P(S_{1:t} \mid O_{1:t})$$
    
      
    
- **两步迭代求解**：
    
      
    1. **预测步（Prediction）**：$P(S_t \mid O_{1:t-1})$
        
          
        
          
        
    2. **更新步（Update）**：$P(S_t \mid O_{1:t}) \propto P(O_t \mid S_t) P(S_t \mid O_{1:t-1})$
        
          
        
          
        

#### 4. MOT 的核心处理流程

1. **目标检测（Object Detection）**：提取边界框与感兴趣目标。
    
      
    
2. **运动估计与轨迹预测（Motion Estimation & Trajectory Prediction）**：根据历史帧预测下一帧位置。
    
      
    
3. **数据关联（Data Association）**：计算预测与检测的匹配代价并分配唯一 ID。
    
      
    
4. **重识别（Re-identification / Re-ID）**：处理目标离开视线或发生长时遮挡后的身份恢复。
    
      
    

#### 5. 经典与前沿 MOT 算法演进

- **SORT (Simple Online and Realtime Tracking)**：
    
      
    - **结构**：基于 Faster R-CNN 目标检测 + 卡尔曼滤波（Kalman Filter）做运动预测 + 匈牙利算法（Hungarian Algorithm）基于 IoU 进行关联。
        
          
        
    - **优点**：结构简单轻量，运行极快（论文中可达 260 FPS）。
        
          
        
    - **缺点**：仅基于位置和线性匀速运动模型匹配，**不包含外观特征（Appearance features）**，遇到长时间遮挡、速度突变或轨迹交错时容易发生 ID 丢失和混淆。
        
          
        
- **DeepSORT**：
    
      
    - 在 SORT 基础上引入深度卷积神经网络提取的**外观特征描述子（Deep Appearance Descriptors）**，结合马氏距离（位置）与余弦距离（外观特征）进行多阶段级联关联，极大改善了遮挡恢复和 ID 切换问题。
        
          
        
- **ByteTrack**：
    
      
    - **核心思想**：打破以往“只保留高置信度检测框”的惯例，在第二关联阶段中利用**低置信度（Low-score）检测框**与现有轨迹做匹配。有效挽救了因遮挡或运动模糊导致检测置信度下降的目标，显著提升了轨迹的连续性。
        
          
        
- **FastTracker**：
    
      
    - 针对复杂交通场景，结合区域约束先验（如锥形投影、ROI 约束）与两阶段关联，并在发生遮挡时引入速度阻尼（DampenVelocity）与检测框膨胀（EnlargeBox）策略。
        
          
        

#### 6. MOT 评估指标体系

- **MOTA（多目标跟踪准确度）**：衡量整体跟踪效果，重点惩罚假阳性（FP）、漏检（FN/Misses）和 ID 切换（ID Switches）：
    
      
    
    $$\text{MOTA} = 1 - \frac{\text{FP} + \text{FN} + \text{ID Sw}}{\text{GT}}$$
    
      
    
- **MOTP（多目标跟踪精度）**：计算匹配框与真实标注框之间的平均几何重叠/距离，衡量**定位质量**。
    
      
    
- **IDF1（身份 F1 分数）**：强调 ID 保持的长期稳定性，衡量能够持续正确追踪同一目标的程度。
    
      
    
- **HOTA（高阶跟踪准确度）**：统一平衡了检测（Detection）、数据关联（Association）与定位（Localization）三者权重。
    
      
    
- **MT（Mostly Tracked）**：被跟踪时长超过生命周期 80% 以上的真实目标比例。
    
      
    

### 第二份讲义：Applications in Biomedical Imaging（生物医学图像应用）

该部分讲义将前述的**运动估计、图像配准与目标跟踪理论**落实到了生物学和临床医学的实际场景中。

  

#### 1. 变化检测应用：数字减影血管造影（DSA）

- **原理**：在注射造影剂前拍摄基准 X 光图像（Mask Image），注射后拍摄实时血管图像（Live Image）。
    
      
    
- **应用**：两者做帧差运算（Live – Mask）并做对比度拉伸，消除骨骼等背景干扰，仅凸显血管结构。
    
      
    
- **问题与解决**：患者呼吸或头部微动会产生强烈的伪影，需借助**模板匹配与图像配准**算法自动进行运动校正。
    
      
    

#### 2. 模板匹配与图像配准（Image Registration）

- **细胞显微运动校正**：通过图像后处理算法消除整个细胞的刚体平移与漂移，以便观察细胞内部的细微变化（Cell fixation）。
    
      
    
- **单模态脑图像配准（Monomodal Brain Registration）**：对不同年龄阶段的 MRI 图像进行空间形变对齐，研究人脑发育过程及发育障碍疾病。
    
      
    
- **多模态医学图像配准（Multimodal Registration）**：
    
      
    - 对齐同一患者不同设备采集的图像（如 **CT 的解剖骨骼细节** + **MRI 的软组织细节**）；
        
          
        
    - 通过最大互信息法（Mutual Information, MI）联合可视化，为医生提供更全面的诊断信息。
        
          
        

#### 3. 光流法应用：心肌组织运动估计（Heart Tissue Motion）

- **场景**：对培养 6 天的心肌单层细胞进行高速相差显微镜录像（24 FPS）。
    
      
    
- **原理**：相差显微图像纹理梯度丰富，非常符合光流基本方程 $\nabla f \cdot \mathbf{v} = -f_t$ 的局部梯度估计条件。
    
      
    
- **输出**：使用色相表示运动方向、明暗强度表示位移大小，精确量化心肌细胞的收缩与舒张动力学。
    
      
    

#### 4. 生物颗粒与细胞跟踪（Particle & Cell Tracking）

- **分子颗粒跟踪（Particle Tracking）**：在极低信噪比和高密度的荧光微观图像中，跟踪微小粒子运动。
    
      
    
- **贝叶斯多目标跟踪**：
    
      
    - 构建包含目标位置、速度、加速度、形状、光强等综合状态向量 $X_t$；
        
          
        
    - 将多目标状态表示为单目标概率密度的混合模型（Mixture Model）以控制状态空间爆炸问题。
        
          
        
- **活细胞跟踪与分裂谱系重建（Cell Lineage Reconstruction）**：
    
      
    - **细胞分割**：采用阈值法、分水岭算法、主动轮廓（Active Contours）以及**水平集（Level-Set）方法**。
        
          
        
    - **拓扑变化处理**：水平集能很好地隐式表示曲线的合并与分裂，非常适用于细胞分裂（Mitosis）过程。
        
          
        
    - **实战案例**：如在果蝇胚胎发育（Drosophila Embryogenesis）中，对成千上万个细胞进行全生命周期跟踪并重建细胞谱系发育树（Lineage Tree）。
        
          
        

### 两份讲义的内在联系

1. **理论到实践**：Part 2-1 提供了通用的计算机视觉 MOT 算法框架（检测、卡尔曼预测、匈牙利关联、深度特征等），Part 2-2 则展示了这些算法在复杂微观和宏观生物医学领域（如血管造影、心肌光流、果蝇细胞谱系追踪）中的特化演变与应用。
    
      
    
2. **技术互补**：日常视频中的 MOT 多使用矩形边界框与深度 Re-ID 特征，而生物医学中的跟踪往往结合了**高精度轮廓形变（如水平集）、贝叶斯滤波与图像配准**，以处理目标的形变、分裂与低信噪比问题。
