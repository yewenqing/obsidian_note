这两份讲义是计算机视觉与模式识别（COMP9517）中关于模式识别（Pattern Recognition）的核心内容，主要涵盖了从基础概念到经典分类、回归算法及评估体系的完整知识链。

  

## 讲义 Part 1：模式识别基础与经典分类器

### 1. 模式识别概览与基础流程

- **核心目标**：自动识别数据（如图像）中的模式与规律。
    
      
    
- **学习范式**：监督学习（有标签）、无监督学习（无标签）、半监督学习与弱监督学习。
    
      
    
- **系统流程**：图像采集 $\rightarrow$ 预处理（图像增强等） $\rightarrow$ 特征提取 $\rightarrow$ 特征选择 $\rightarrow$ 学习系统（模型构建） $\rightarrow$ 系统测试评估。
    
      
    
- **特征向量（Feature Vector）**：用数值向量 $\mathbf{x} = [x_1, \dots, x_d]^T$ 表征目标属性（如颜色、纹理、形状），要求具备平移、旋转及光照不变性等鲁棒性。
    
      
    

### 2. 最近类均值分类器（Nearest Class Mean, NCM）

- **原理**：计算每个类别的中心（Centroid / Mean $\boldsymbol{\mu}_k$），对新样本计算其与各类别中心的欧氏距离，归类至最近的类别中心。
    
      
    
- **优缺点**：
    
      
    - _优点_：简单、快速，在类别紧凑且相互远离时表现好。
        
          
        
    - _缺点_：对多峰分布（Multimodal）和非球形分布处理极差，对噪声、离群点和缺失值敏感。
        
          
        

### 3. K-近邻分类器（K-Nearest Neighbors, K-NN）

- **原理**：无显式训练过程（Instance-based / Lazy learning）。测试时计算新样本与所有训练样本的距离（连续变量常用欧氏距离，离散变量常用汉明距离），由最近的 $K$ 个邻居进行多数投票（Majority Vote）决定标签。
    
      
    
- **优缺点**：
    
      
    - _优点_：简单直观、无先验分布假设、能形成非线性决策面。
        
          
        
    - _缺点_：样本量大时预测极慢；易受维度灾难（Curse of Dimensionality）影响；需要特征尺度一致；参数 $K$ 的选取敏感。
        
          
        

### 4. 贝叶斯决策论（Bayesian Decision Theory）

- **核心思想**：基于概率框架做出期望错误率最低的“软决策”。
    
      
    
- **贝叶斯公式**：
    
      
    
    $$p(c_i \mid \mathbf{x}) = \frac{p(\mathbf{x} \mid c_i) p(c_i)}{p(\mathbf{x})} \propto p(\mathbf{x} \mid c_i) p(c_i)$$
    
    - $p(c_i)$ 为先验概率（Prior），$p(\mathbf{x} \mid c_i)$ 为类条件概率密度（Likelihood），$p(c_i \mid \mathbf{x})$ 为后验概率（Posterior）。
        
          
        
- **最大后验决策（MAP）**：$\hat{c} = \arg\max_i p(c_i \mid \mathbf{x})$。
    
      
    
- **贝叶斯风险与损失（Bayes Risk / Cost）**：当各类误判代价不同时，引入损失矩阵 $\lambda(\alpha_i \mid c_j)$，目标转为**最小化条件风险**：
    
      
    
    $$R(\alpha_i \mid \mathbf{x}) = \sum_j \lambda(\alpha_i \mid c_j) p(c_j \mid \mathbf{x})$$
    

### 5. 决策树（Decision Trees）

- **原理**：自顶向下的树状规则模型，内部节点表示特征测试，分支表示测试输出，叶节点包含最终类别。
    
      
    
- **特征选择准则**：
    
      
    - **信息熵（Entropy）**：衡量数据的不确定性，$H(S) = -\sum p_i \log_2 p_i$。
        
          
        
    - **信息增益（Information Gain, IG）**：$IG(S, f) = H(S) - H(S \mid f)$，分裂时选取**信息增益最大**的特征。
        
          
        
- **优缺点**：可解释性强、能同时处理数值与类别特征；但容易**过拟合**，且贪心算法只能产生轴对齐（Axis-aligned）的分割面。
    
      
    

### 6. 集成学习与随机森林（Random Forests）

- **原理**：通过构建多棵决策树（Bagging / Bootstrap 抽样样本，节点分裂时随机选取 $m \ll M$ 个特征子集），测试时采用多数投票集成预测。
    
      
    
- **误差关键因素**：
    
      
    1. 树之间的**相关性（Correlation）**：相关性越低，泛化能力越好。
        
          
        
    2. 单棵树的**强度（Strength）**：单树越强，森林整体误差越低。
        
          
        
- **参数 $m$ 的权衡**：减小 $m$ 会同时降低相关性和单树强度，需折中调优。
    
      
    

## 讲义 Part 2：支持向量机、多分类、评估与回归

### 1. 线性分类器与支持向量机（SVM）

- **线性分类器**：$f(\mathbf{x}) = \mathbf{w}^T \mathbf{x} + b$。
    
      
    
- **硬间隔 SVM（Hard-margin SVM）**：
    
      
    - 寻找能最大化分类间隔（Margin $\rho = \frac{1}{\Vert{}\mathbf{w}\Vert{}_2}$）的超平面，等价于凸二次规划（QP）问题：
        
          
        
        $$\min_{\mathbf{w}, b} \frac{1}{2} \Vert{}\mathbf{w}\Vert{}_2^2 \quad \text{s.t.} \quad y_i(\mathbf{w}^T \mathbf{x}_i + b) \ge 1, \; \forall i$$
        
- **软间隔 SVM（Soft-margin SVM）**：
    
      
    - 针对线性不可分或带噪声数据，引入松弛变量 $\xi_i \ge 0$ 和惩罚参数 $C$：
        
          
        
        $$\min_{\mathbf{w}, b, \{\xi_i\}} \frac{1}{2} \Vert{}\mathbf{w}\Vert{}_2^2 + C \sum_i \xi_i \quad \text{s.t.} \quad y_i(\mathbf{w}^T \mathbf{x}_i + b) \ge 1 - \xi_i$$
        
    - $C$ 较小更容忍误分类（追求大间隔）；$C$ 较大则严格减少误分类（间隔较小）；$C \to \infty$ 退化为硬间隔。
        
          
        
- **非线性 SVM 与核技巧（Kernel Trick）**：通过核函数隐式映射到高维空间，将其转化为高维下的线性可分问题（如结合 HOG/SIFT 特征的目标检测）。
    
      
    

### 2. 多分类策略（Multiclass Classification）

对于本质为二分类的算法，通常有两种扩展方式：

  

- **一对多（One-vs-Rest / OvR）**：训练 $K$ 个分类器（每个代表 1 类 vs 其它所有类），选取置信度最高的类别。
    
      
    
- **一对一（One-vs-One / OvO）**：训练 $\frac{K(K-1)}{2}$ 个两两比较分类器，通过投票决定最终预测。
    
      
    

### 3. 分类性能评估体系

- **混淆矩阵（Confusion Matrix）**：记录真实类别与预测类别之间的交叉统计。
    
      
    
- **核心指标**：
    
      
    - **Accuracy**：$\frac{TP + TN}{TP + TN + FP + FN}$
        
          
        
          
        
    - **Precision（精确率）**：$\frac{TP}{TP + FP}$（预测为正中真正为正的比例）
        
          
        
    - **Recall / Sensitivity（召回率）**：$\frac{TP}{TP + FN}$（真实正样本中被检出的比例）
        
          
        
    - **F1-Score**：精确率与召回率的调和平均值 $\frac{2PR}{P + R}$
        
          
        
          
        
- **ROC 曲线与 AUC**：以假正率（FPR）为横轴、真正率（TPR / Recall）为纵轴绘制曲线，曲线下面积（AUC）越接近 1 表示综合判别能力越优。
    
      
    

### 4. 监督学习之回归（Regression）

- **线性回归与最小二乘法（Least Squares Fitting）**：
    
      
    - 模型：$\hat{y} = \mathbf{x}\mathbf{W}$
        
          
        
          
        
    - 最小化残差平方和 $RSS(\mathbf{W}) = (\mathbf{Y} - \mathbf{X}\mathbf{W})^T(\mathbf{Y} - \mathbf{X}\mathbf{W})$
        
          
        
          
        
    - 解析解（正规方程）：$\hat{\mathbf{W}} = (\mathbf{X}^T\mathbf{X})^{-1}\mathbf{X}^T\mathbf{Y}$
        
          
        
          
        
- **回归评估指标**：
    
      
    - **RMSE**（均方根误差，对大误差惩罚重）与 **MAE**（平均绝对误差）。
        
          
        
    - **$R^2$（决定系数）** 与 **Adjusted $R^2$**（校正特征数量后的指标，防止多加无用特征虚高）。
        
          
        

### 5. 数据预处理与交叉验证

- **特征标准化**：
    
      
    - **Z-score**：$\frac{x - \mu}{\sigma}$（映射为标准正态分布）。
        
          
        
    - **Min-Max 归一化**：$\frac{x - x_{\min}}{x_{\max} - x_{\min}}$（缩放至 $[0, 1]$）。
        
          
        
- **K 折交叉验证（K-fold Cross Validation）**：将训练数据均分为 $K$ 份，轮流用 1 份做验证、其余 $K-1$ 份做训练，用于防止过拟合及进行超参数调优（注意：测试集不可用于超参数选择）。
