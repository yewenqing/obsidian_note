## 一、 图像拼接与几何空间变换（Image Stitching & Spatial Transformations）

### 1. 基础图像拼接流程（基于 SIFT）

- **特征提取与最近邻匹配**：从具有重叠区域的不同视角图像中提取 SIFT 关键点 。在欧氏空间中计算特征向量的距离，通过寻找最近邻（Nearest Neighbour）建立两幅图像之间的点对点对应关系（Correspondences）。
    
- **关系估计与仿射投影（Warping）**：利用匹配的样本点估计底层的几何空间变换模型 ，进而将其中一张图像的所有像素投影变换（Warp）到另一张图像的坐标空间中，最终缝合混叠，生成全景图 。
    

### 2. 常见的 2D 空间变换模型对比

根据变换的复杂度和保持的几何特性，有以下几种主要数学模型：

|**变换模型**|**自由度/参数**|**几何保持特性**|**关键数学直观与公式表达**|
|---|---|---|---|
|**平移 (Translation)**|2 ($T_X, T_Y$)|保持距离、角度、大小不变|$X' = X + T_X$ ；引入额外维度以矩阵形式表示 。|
|**刚体变换 (Rigid)**|3 (旋转 $\alpha$ + 平移)|保持透视距离与角度不变|隐式假设围绕坐标原点或图像中心旋转 。|
|**均匀缩放 (Scaling)**|1|保持角度和形状，不保持大小|$X' = s \cdot X$ 。|
|**仿射变换 (Affine)**|6 ($A, B, C, D, E, F$)|保持**平行线**依旧平行|融合了平移、旋转、缩放与剪切（Shear）。|
|**透视/单应性 (Perspective)**|8|直线仍为直线，但平行线会交于**消隐点**|基于**齐次坐标（Homogeneous Coordinates）**，坐标需被 $W'$ 缩放归一 。与针孔相机模型密切相关 。|

### 3. 线性最小二乘拟合（Linear Least Squares Fitting）

- **超定方程组（Overdetermined System）**：以仿射变换为例，求解 6 个未知参数 $P$ 。因为每一对匹配点可提供 2 个独立方程（分别针对 $X$ 和 $Y$ 轴变化），当采样点数 $N > 3$ 时，方程数（$2N$）大于未知数 。
    
- **噪声与优化**：实际测量坐标极易受到噪声污染，无法直接求解闭式解（如 $P = A^{-1}B$ 形式不可行，因为 $A$ 往往不可逆）。
    
- **最小二乘核心**：转换为线性系统 $A \times P = B$ 后 ，通过**最小化预测值与实际观测值之间的平方差**来求解最优的参数向量 $P$ ：
    
    $$\min_P ||AP - B||^2$$
    

## 二、 RANSAC（随机抽样一致）算法

### 1. 离群点（Outliers）的危害

在利用相似度进行特征描述符匹配时，往往会产生**误匹配（Mismatching）** 。这些严重偏离潜在几何变换规律的错误匹配点被称为**离群点（Outliers）** 。传统的最小二乘拟合仅能容忍轻微的高斯噪声 ，若混入离群点，拟合结果会产生严重偏差 。

### 2. RANSAC 算法核心思想与步骤

RANSAC 是一种基于**随机抽样**的鲁棒迭代算法 ，其基本假设是数据集中大部分点为局内点（Inliers）。

```
                      ┌──────────────────────────────────────┐
                      │ 1. 随机抽样最小子集，拟合初始模型参数 │
                      └──────────────────┬───────────────────┘
                                         │
                                         ▼
                      ┌──────────────────────────────────────┐
                      │ 2. 设定距离阈值，统计符合模型的局内点 │
                      │    (Inliers) 数量并记录评分          │
                      └──────────────────┬───────────────────┘
                                         │
                                         ▼
            否        ┌──────────────────────────────────────┐
      ┌───────────────┤ 3. 是否达到终止条件 (如迭代 100 次)?  │
      │               └──────────────────┬───────────────────┘
      ▼                                  │ 是
[进入下一轮循环]                          ▼
                      ┌──────────────────────────────────────┐
                      │ 4. 保留最佳模型，用该模型关联的全部   │
                      │    局内点重新计算/精细化模型参数     │
                      └──────────────────────────────────────┘
```

- **抽取最小子集（Minimal Set）**：例如拟合二维空间直线只需 2 个点 ，估计仿射变换需要 3 对点。采用极小的数据集可以有效降低单次抽样中包含离群点的概率 。
    
- **终止/收敛条件**：1）设定的最大迭代次数（如循环 100 次）；2）模型中心位置或局内点比例收敛，不再发生剧烈变化 。
    

## 三、 特征编码：视觉词袋模型（Bag-of-Words, BoW）

### 1. 引言与动机

- **问题**：SIFT 特征是基于局部关键点的，每张图像提取的关键点数量不同（非固定维度）。而高层图像理解（如图像分类）通常需要一个统一的、**固定维度的全局特征向量** 。
    
- **思想来源**：借鉴自然语言处理（NLP）中的文本检索。将图像看作一篇文章，图像中的局部特征块看作短语和单词 。
    

### 2. 算法核心两大阶段：训练与测试

词袋模型的核心架构分为**构建视觉字典（Vocabulary）**、**训练分类器**与**线上测试** ：

```
【训练阶段 (Training)】 [cite: 1431, 1443]
 训练图像集 ──> 提取所有局部 SIFT 描述符 ──> K-Means 聚类 ──> 提取聚类中心作为“视觉单词” (Visual Words) ──> 建立词汇表 [cite: 1448, 1457, 1458]
                                                                        │
                                                                        ▼
 训练图像集 ──────────────────────────────> 根据词汇表映射为频率直方图 ──> 训练分类器 (如 SVM) [cite: 1440, 1503, 1997]

【测试阶段 (Testing)】 
 测试图像 ──> 提取 SIFT 描述符 ──> 寻找词汇表中最近邻的视觉单词进行分配 [cite: 1438, 1490] ──> 构建直方图向量 ──> 分类器预测标签 [cite: 1440, 1497, 1503]
```

### 3. 基于 K-Means 聚类构建视觉单词

- **点云量化**：SIFT 描述符是一个 128 维的向量 。将成千上万张训练图的 SIFT 向量混合在 128 维空间中形成一个庞大的点云 。
    
- **K-Means 聚类步骤** ：
    
    1. **初始化**：手动给定超参数值 $K$（类簇数量），在空间中随机初始化 $K$ 个聚类中心 。
        
    2. **数据分配（Iterate 1）**：计算每个特征点到 $K$ 个中心的欧氏距离，将各点分配给最近的中心 。
        
    3. **中心更新（Iterate 2）**：计算每个类簇内所有数据样本的坐标均值（Mean），更新聚类中心的位置 。
        
    4. **终止条件**：中心坐标收敛（变化低于阈值）或达到最大迭代次数 。
        
- **结果**：最终迭代稳定的 **$K$ 个聚类中心（均值向量）** 就是词汇表（Vocabulary）中的 **“视觉单词”（Visual Words）** 。
    

### 4. 特征直方图构建

- 给定一张新图像，提取其所有的 SIFT 关键点 。
    
- 遍历这些关键点，在词汇表中找出与之欧氏距离最近的视觉单词中心，进行近邻分配（投赞成票）。
    
- 统计落入这 $K$ 个视觉单词的频次，拼接为一个 **$K$ 维的频率直方图（Histogram）**。这个直方图就是整张图像的全局特征向量（BoW 表示）。
    

5. 高级补充说明

- **局部描述符可替换性**：词袋编码过程不局限于 SIFT，同样可使用 LBP、SURF、BRIEF、ORB 等局部特征 。
    
- **更先进的编码技术**：除了简单的均值直方图，还有诸如 **VLAD** 和 **Fisher Vector（费舍尔向量）** 等高级算法，它们会同时编码高阶维度之间的相关性与残差信息 。常用的开源工具库为 **VLFeat.org** 。
    

## 四、 形状特征（Shape Features）

形状特征属于全局大尺度物体轮廓信息的提炼（通常在图像分割获得目标 Mask 后提取）。

1. 核心挑战

2. **刚体变换不变性**：对旋转、平移、平移位置不敏感 。
    
3. **非刚性变形容忍度**：对尺度缩放（Scaling）或透视角度改变具有一定抗干扰能力 。
    
4. **未知对应关系**：两目标比对时，无法预知边界上哪两个点在几何上互为对应点 。
    

### 2. 简单几何形状描述符

以下指标多属于粗粒度的全局特征，往往会将复杂的形状细节压缩为极少数的数值：

- **净面积 (Net Area)**：物体掩码区域内包含的像素点总数 。
    
- **凸包与凸包面积 (Convex Area)**：能完全围住、包裹该不规则轮廓的最小凸多边形（Convex Hull）的面积 。
    
- **凸缺陷 (Convex Deficiency)**：凸包面积与物体本身真实面积的差集集合（对于完美凸图形，该值为 0）。
    
- **紧凑度 (Compactness)**与**圆度 (Circularity)**（互为反向相关 ）：
    
    - **紧凑度**：与物体具有**相同周长**的圆的面积，除以该物体的实际面积 。
        
    - **圆度**：物体面积的 $4\pi$ 倍，除以其周长的二次方 ：
        
        $$\text{Circularity} = \frac{4\pi A}{P^2}$$
        
        （完美圆形的圆度为 1 ；越不规则、凹凸不平的轮廓，周长 $P$ 越大，圆度值越低 ）。
        
- **细长度 (Elongation)**与**离心率 (Eccentricity)**（皆用于描述物体是细长扁平还是浑圆 ）：
    
    - **细长度**：物体外接矩形（Bounding Box）的长度与宽度之比 。
        
    - **离心率**：主轴方向上，物体的短轴（Minor Axis）长度与长轴（Major Axis）长度之比 。
        

### 3. 精细边界与轮廓描述符

为了保留低层边界细节，可使用更精细的Fingerprint描述方式：

- **链码描述符 (Chain Code Descriptor)**：设定固定的 8 方向编码本（0-7 表示八个移动方位）。从边界某个起始点出发，顺时针或逆时针绕行一圈，顺序记录下一步移动的方向编码，最终级联为一个离散的长向量（具有紧凑的边界压缩能力）。
    
- **局部曲率描述符 (Local Curvature Descriptor)**：在连续域下沿着轮廓弧长 $s$ 移动 ，连续记录切线方向或弯曲程度的变化率 $\kappa$ 。
    
    - **几何直观**：在边界极小的局部贴合一个完美的圆形（密切圆），曲率定义为贴合圆半径的倒数：$K(s) = \pm \frac{1}{r(s)}$ 。转弯越急剧，拟合圆越小，曲率绝对值越大 。
        
    - **符号约定**：凸起（Convex）部分对应正曲率，凹陷（Concave）部分对应负曲率 。
        
- **全局曲率描述符**（由局部曲率积分提炼而来 ）：
    
    - **总弯曲能量 (Total Bending Energy)**：$B = \oint_C \kappa^2(s) ds$（对曲率平方求积分，圆形的弯曲能量最小，为 $B = \frac{2\pi}{r}$）。
        
    - **总绝对曲率 (Total Absolute Curvature)**：$K = \oint_C |\kappa(s)| ds$（忽略符号，凸形目标的总绝对曲率最小，为 $K = 2\pi$）。
        
- **径向距离描述符 (Radial Distance Descriptor)**：确定目标的几何质心 $C$ ，顺序计算轮廓上各像素点到质心的欧氏距离 $d(i)$ 。
    
    - **尺度不变性**：通过将所有距离除以最大径向距离进行归一化实现 。
        
    - **粗糙度量化**：可以通过归一化信号穿越其均值（Mean）的次数来衡量边界的粗糙程度 。
        

## 五、 形状上下文（Shape Context）与形状匹配

形状上下文是一种先进的、基于点对的点级局部形状特征描述符 。

### 1. 形状上下文编码步骤

1. **边缘点采样**：对输入的查询图和图库图进行预处理（如使用 **Canny 边缘检测**：包含高斯滤波、计算梯度幅值与方向、非极大值抑制、双阈值滞回处理及边缘跟踪等经典步骤），在提炼出的轮廓边缘上采样得到 $n$ 个离散的点 $p_i$ 。
    
2. **极坐标系切分**：以当前点 $p_i$ 为坐标原点建立一个对数极坐标系（Radial Coordinate System），在角度（如 12 个等分角度）和距离（对数尺度分隔）上划分为多个小格子（Bins）。
    
3. **构建直方图**：统计其余 $n-1$ 个点分别落入各个 Bin 的数量 。每个采样点最终都能获得一个专属的二维直方图 $h_i(k)$，这就是该点的形状上下文特征 。
    

### 2. 完整的形状匹配算法流程（Shape Matching）

当需要比对两个不同的形状 $P$ 和 $Q$ 时，执行以下操作：

- **Step 1 & 2**：采样边缘点并为两形状中的每个点分别计算形状上下文直方图 $h_i$ 和 $h_j$ 。
    
- **Step 3：构建成本矩阵（Cost Matrix）**：利用 $\chi^2$（卡方检验）测试公式，两两比对 $P$ 中任一点 $p_i$ 与 $Q$ 中任一点 $q_j$ 的直方图差异，填入一个 $n \times m$ 的代价矩阵中 ：
    
    $$C(p_i, q_j) = \frac{1}{2} \sum_{k=1}^K \frac{[h_i(k) - h_j(k)]^2}{h_i(k) + h_j(k)}$$
    
- **Step 4：求解一对一匹配（1-to-1 Matching）**：这属于一个结构化分配问题，目的是在整个成本矩阵中寻找一种全局点对点一一对齐的映射关系 $\pi$，使总体匹配代价之和最小 ：
    
    $$\min_\pi H(\pi) = \sum_{i} c(p_i, q_{\pi(i)})$$
    
- **Step 5：估计全局几何变换**：在获得最佳对齐点对后，估计一个全局空间变换模型（如仿射变换），并使用**最小二乘法**或 **RANSAC** 进行鲁棒性拟合，从而得到最优的全局变换矩阵 $T$（用以消除形状间的整体平移、缩放与旋转差异）。
    
- **Step 6：计算最终形状距离（Shape Distance）**：在通过全局变换 $T$ 对齐后，综合计算两个形状之间相互的最近点代价均值作为两形状的最终距离 $D(P,Q)$ 。
    

## 六、 方向梯度直方图（Histogram of Oriented Gradients, HOG）

HOG 特征是计算机视觉领域在深度学习爆发前，用于目标检测（特别是行人/人类检测）的绝对标杆算法（State-of-the-art）。它通过在一组密集、重叠的局部网络中编码梯度方向的统计分布来捕获目标的边缘和表观轮廓 。

### 1. HOG 的底层计算步骤与空间组织架构

与 SIFT 依赖初始分割或特定关键点检测不同，HOG 是一种稠密采样（Dense Sampling）算法 。

```
【图像像素层 (Pixels)】
 对输入 Patch 中的每个像素点，计算水平和垂直梯度，进而得到其【梯度幅值 (Magnitude)】与【梯度方向 (Orientation)】 [cite: 1728, 2389]。
       │
       ▼
【细胞单元层 (Cells)】
 将图像划分为密集的 【8×8 像素的微小 Cell】 [cite: 1730, 2418]。
 将 0-180 度的无向角度等分为 【9 个极角区间 (Bins)】 [cite: 1732, 1735, 2402]。
 遍历 Cell 内所有像素，将其梯度幅值作为权重（贡献分），累加映射到对应的无向角度 Bin 中，形成一个 9 维的 Cell 直方图 [cite: 1736, 2400, 2403]。
       │
       ▼
【大块区域层 (Blocks)】
 为了对抗光照与阴影变化，引入滑动重叠的【2×2 Cells 组成一个大 Block】（即 16×16 像素）[cite: 1740, 1741, 2417]。
 将一个 Block 内包含的 4 个 Cell 的直方图（4 × 9维）级联起来，并在该 Block 局部区域内执行【块归一化 (Block Normalization)】 [cite: 1743, 1747, 2414, 2415]。
       │
       ▼
【整体窗口描述符 (Window Descriptor)】
 针对经典的行人检测窗口（通常包含 7×15 个横纵滑动 Block）[cite: 1740, 2416]。
 将所有 Block 归一化后的特征级联，最终形成一个固定维度的超长全局特征向量 [cite: 1745, 2414]：
 最终总特征维度 = 7 × 15 (Blocks) × 2 × 2 (Cells/Block) × 9 (Bins/Cell) = 【3,780 维】 [cite: 1745, 2420]。
```

### 2. 行人检测系统：滑动窗口与分类

- **训练阶段**：从训练数据集中裁剪出大量窗口，手动标注标签（“人”或“背景”）。计算每个窗口的 3,780 维 HOG 特征向量，输入支持向量机（SVM）训练出决策边界 。
    
- **测试阶段**：对于一幅任意尺寸的新测试图，使用固定尺寸的滑动窗口（Sliding Window）在全图多尺度、全方位扫描 ，实时提取局部 HOG 特征送入 SVM 判别，最终输出一幅包含行人边界框的响应图 。
    

### 3. 高级变体：可变形部件模型（Deformable Parts Model, DPM）

- **动机**：人体姿态高度灵活、柔性可变，且极易受局部遮挡影响，单一的硬性刚体 HOG 模板在面对各种动作变化时容易失效 。
    
- **解耦思路**：将完整的人体检测拆分为一个根检测器（Root Filter）**和多个**部件检测器（Part Filters）的联合架构 。
    
    - **根检测器**：负责在低分辨率下捕获整个人体宏观的 HOG 粗略轮廓 。
        
    - **部件检测器**：在双倍高分辨率下，独立、精细地检测头部、手臂、腿部等各个关键人体器官部件的位置 。
        
- **共同投票机制**：最终将空间部件的几何相对形变代价（Deformation Models）与整体检测置信度动态混叠融合，允许部件发生位移，联合投票判定 。即使由于姿态古怪导致整体检测评分极低，只要局部部件置信度足够高，系统依然能实现稳定出色的细粒度拦截和识别 。
    

## 💡 经典期末考试真题解析（结合讲义 Slide 46）

> **题目背景：** 给定一幅细胞/微生物图像的图像分割结果（幻灯片第 46 页插图），其中包含各类不规则的不连续目标 。图中目标被分类为两个不同的类别，并分别用**红色**和**绿色**指代 。 现希望通过计算某一单一度量指标，并应用一个简单的硬阈值（Thresholding）来实现该分类结果 。
> 
> **核心提问：** 如果我们分别计算各个目标的**圆度（Circularity）**与**离心率（Eccentricity）**，请问哪一个（或哪些）指标可以完美地产生图中所示的分类结果（即区分开红绿两类目标）？ A. 只有圆度 (Only circularity)
> 
> B. 只有离心率 (Only eccentricity)
> 
> C. 圆度和离心率都可以 (Both)
> 
> D. 两个都不行 (Neither)

### 🎯 深度解题思路与正确答案

正确答案：A. Only circularity（只有圆度）

#### 详细推导分析：

1. **细看图像中物体的几何特性**：
    
    - **红色目标**：全都是饱满、圆润的块状结构（近圆形或近椭圆形）。
        
    - **绿色目标**：包含两种截然不同的形态。一种是一个**空心的圆环（带孔的绿色圆圈）**，另一种是多条**细长、弯曲的条状物/弧形结构**。
        
2. **评估“离心率（Eccentricity）”为何失效**：
    
    - 根据定义，离心率描述的是物体长短轴的比例关系（对边界的长宽比极度敏感）。
        
    - 图像右上方那个**绿色的空心圆环**，它的外轮廓长轴和短轴几乎完全相等。因此，这个绿色圆环计算出来的离心率会非常接近于 1（意味着它在主轴上表现得很对称、很“圆”）。
        
    - 然而，那些**红色的细胞块**同样很饱满，长短轴也近乎相等，其离心率也会非常接近于 1 。
        
    - **结论**：如果单纯使用离心率并设定一个阈值，系统**绝对无法**把那个绿色的空心圆环和红色的圆形块状物给区分开。所以离心率失效 。
        
3. **评估“圆度（Circularity）”为何能完美胜任**：
    
    - 根据公式 $\text{Circularity} = \frac{4\pi A}{P^2}$，圆度取决于物体的**面积与周长平方的比率** 。
        
    - 对于**红色目标**：它们是实心的、边界平滑的圆形区域，在相同的周长下拥有极大的面积，因此它们的圆度值会非常高（极度接近 1）。
        
    - 对于**绿色目标**：
        
        - 那几条细长的弯曲条状物，其周长很大但包裹的内部面积极小，因此圆度值极低 。
            
        - 关键看那个**绿色的空心圆环**：因为它是空心的，在计算周长 $P$ 时，它**同时包含了外圆边界周长和内孔边界周长**（周长双倍激增）；而它的实际面积 $A$ 却由于中间被掏空而大幅减小。根据公式分母剧烈变大、分子变小，其**圆度值会发生断崖式下跌**，变得非常小 。
            
    - **结论**：所有的绿色目标（无论是细长条还是空心环）其计算出来的圆度值都会非常低；而所有的红色目标其圆度值都会非常高。因此，我们只需要简单地切一个中间阈值（如大于 0.75 为红，小于 0.75 为绿），就能毫无差错地实现图中的分类。所以只有圆度可行 。
