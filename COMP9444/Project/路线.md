对于你们 COMP9444 的小组项目 013. 使用大语言模型进行生物医学命名实体识别（Biomedical NER），我建议把项目设计成一条有明确研究问题、实验对比和分析深度的路线，而不是简单地下载 BioBERT、Fine-tune 一次，然后报告 F1 Score。

结合你之前发的评分细则，我认为最合适的方案是：

以 BioBERT 为核心模型，以 PubMedBERT 为对比模型，通过领域预训练模型比较、微调策略实验和错误分析，研究生物医学领域预训练对疾病实体识别的影响。

这样既能满足项目要求，又能在 Notebook、Report 和 Presentation 中展示足够的实验深度。

# 一、先明确项目最终要做什么

推荐项目题目

Evaluating Domain-Specific Transformers for Biomedical Named Entity Recognition

面向生物医学命名实体识别的领域专用 Transformer 模型评估

核心研究问题

1. 生物医学领域预训练模型是否优于通用 BERT？
2. BioBERT 和 PubMedBERT 在疾病实体识别任务上有什么性能差异？
3. 不同微调策略会如何影响模型性能？
4. 模型在哪些类型的疾病实体上容易犯错？

需要先注意一个重要限制：

你们选择的 NCBI Disease Corpus 只标注疾病实体，并不包含完整的药物、基因和解剖学实体标注。

因此，项目实际应聚焦于：

Disease Named Entity Recognition（疾病命名实体识别）

而不是声称能够同时识别疾病、药物、基因和解剖学实体。

如果后续希望研究跨领域泛化，可以扩展到其他生物医学 NER 数据集，但不建议一开始就增加太多任务。

模型需要识别完整的疾病实体边界，而不仅是判断某个单词是否与医学相关。

数据预处理建议：

1. 使用官方 Train / Validation / Test 划分，不要随机重新划分后混用。
2. 使用每个模型对应的 Tokenizer。
3. 将原始 BIO 标签与 WordPiece 子词对齐。
4. 对 Padding、特殊 Token 及不参与损失计算的子词位置设置 `-100`。
5. 保留原始实体及其位置，便于后续做错误分析。

尤其要注意：不同模型的 Tokenizer 可能不同，所以需要统一实体级评价方式，确保比较公平。

## 阶段 3：微调 BioBERT 和 PubMedBERT

这是项目的核心实验。

推荐模型如下：

| 模型         | 作用       | 预训练特点                     |
| ---------- | -------- | ------------------------- |
| BERT-base  | Baseline | 通用文本                      |
| BioBERT    | 主要实验模型   | 在通用 BERT 基础上继续使用生物医学文本预训练 |
| PubMedBERT | 对比模型     | 从头使用生物医学文本预训练             |

PubMedBERT 在 Hugging Face 上也以 BiomedBERT 名称发布。对于 NCBI Disease 这样的 PubMed 摘要数据，可以优先选择仅在摘要上预训练的版本：`microsoft/BiomedNLP-BiomedBERT-base-uncased-abstract`。

三个模型尽可能采用相同的训练预算和评价流程；每个模型独立使用对应的 Tokenizer。

## 阶段 4：设计有研究价值的改进实验

这是我认为最值得投入精力的部分。

如果只是训练三个预训练模型并比较 F1，能够完成基本任务，但研究深度有限。

建议增加两组实验。

### 实验 A：微调策略对比

选择 BioBERT，比较：

| 实验 | 方法                  | 目的                     |
| -- | ------------------- | ---------------------- |
| A1 | Full Fine-tuning    | 完整微调所有参数               |
| A2 | Frozen Encoder      | 冻结 BERT Encoder，只训练分类头 |
| A3 | Partial Fine-tuning | 只解冻最后几层 Transformer    |

研究问题：

在有限的生物医学标注数据下，是否有必要更新整个预训练模型？

需要比较：

- Entity-level F1。
- 训练时间。
- 可训练参数数量。
- 是否出现过拟合。

这样你们就不仅是在调用现成模型，而是在分析不同微调方法的实际效果。

## 阶段 5：模型评估与错误分析

评分细则中 Results 和 Discussion 合计 5 分，因此这部分应作为重点。

### 主要评价指标

- Precision：预测为疾病实体的结果中，有多少是正确的。
- Recall：真实疾病实体中，有多少被模型正确识别。
- F1 Score：Precision 和 Recall 的调和平均数。

建议以严格实体级 F1（Strict Entity-level F1）作为主要指标。

只有预测的实体起止位置和实体类型都正确，才算识别成功。

最终结果表可以设计成这样：

| 模型         | Precision | Recall | F1  |
| ---------- | --------- | ------ | --- |
| BERT-base  | 待实验       | 待实验    | 待实验 |
| BioBERT    | 待实验       | 待实验    | 待实验 |
| PubMedBERT | 待实验       | 待实验    | 待实验 |
| 最佳改进方案     | 待实验       | 待实验    | 待实验 |

不要提前填写假设的性能结果。最好在计算资源允许时使用 3 个随机种子，并报告均值与标准差。

### 错误分析应该做什么？

建议重点研究四种错误：

| 错误类型               | 分析方向               |
| ------------------ | ------------------ |
| False Positive     | 普通医学术语被错误识别为疾病     |
| False Negative     | 模型遗漏了真实疾病实体        |
| Boundary Error     | 识别了部分疾病名称，但实体边界不完整 |
| Abbreviation Error | 疾病缩写识别错误           |

还可以进一步比较：

- 短实体与长实体的识别效果。
- 单词实体与多词实体的识别效果。
- 训练集中常见实体与低频实体的表现。
- 含复杂医学术语的句子。

这些分析有助于解释为什么某个模型更好，而不仅是展示分数。

# 六、如果你们是 4 人小组，如何分工？

建议采用“每个人负责一个核心模块，但所有人共同理解最终结果”的方式。

| 成员 | 主要负责                 | 最终贡献               |
| -- | -------------------- | ------------------ |
| A  | 数据处理与 EDA、Baseline   | 数据分析图、BERT 结果      |
| B  | BioBERT 训练与微调策略实验    | BioBERT 结果、消融实验    |
| C  | PubMedBERT 训练与数据规模实验 | PubMedBERT 结果、学习曲线 |
| D  | 统一评价、错误分析、结果整合       | 对比表、错误案例、讨论        |

所有成员共同参与 Report 和 Presentation，并各自讲解自己负责的研究内容。由于 Presentation 有个人评分，每个人都应该能够解释自己的实验方法、结果和结论。

## 八、最重要的建议

对于 COMP9444 这样的课程项目，实验设计是否合理、结果是否可信、分析是否深入，比单纯追求最高 F1 更重要。

你们最终应该能清楚回答三个问题：

1. 为什么生物医学领域预训练模型可能优于通用 BERT？
2. 哪一种模型和微调策略在 NCBI Disease 上表现最好，为什么？
3. 模型在哪些情况下仍然容易出错，这些问题说明了什么？

这三个问题如果能用实际实验结果支撑，你们的 Notebook、Report 和 Presentation 就会形成一条完整的研究主线。
