```
class Solution:
    def longestConsecutive(self, nums: list[int]) -> int:
        if nums == []:
            return 0
        numset = set(nums)
        max_len = 0      
        l = 0
        for n in numset:
            if n-1 not in numset:
                l = 0
                k = n
                while k in numset:
                    l +=1
                    k +=
                max_len = max(l, max_len)
        return max_len
```

使用 Set 记录数据
通过 n-1 在不在 set 中判断是否为序列头
若为序列头则进行序列长度计算
虽然是双重嵌套循环但是若不是序列头外层循环会直接跳过，
所以时间复杂度可压缩至O(N)
